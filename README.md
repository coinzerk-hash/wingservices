# WingServices

موقع متكامل (Full-stack) لبيع خدمات Old School RuneScape: بوصات، تدريب مهارات، مهام، مينيجيمز، دعم آيرون مان، وفارمينج ذهب — مبني بتصميم مستقل خاص بعلامة WingServices، مع شات بوت ذكاء اصطناعي حقيقي مدمج بـ Claude API.

## المميزات المنفذة

- **كتالوج خدمات** مقسم لفئات (Boss Services, Skilling, Quests & Diaries, Minigames, Ironman Support, GP Farming) مع فلترة حسب الفئة.
- **سلة شراء حقيقية** (إضافة / تعديل الكمية / حذف) محفوظة في قاعدة بيانات SQLite مربوطة بكوكي لكل زائر (تشتغل حتى بدون تسجيل دخول).
- **تسجيل دخول / حساب جديد** بكلمات مرور مشفرة (bcrypt) وجلسات عبر JWT في كوكي httpOnly.
- **صفحة دفع (Checkout)** تجمع اسم الحساب (RSN)، يوزر الديسكورد، وطريقة الدفع (Crypto, PayPal, Cash App, Venmo, OSRS Gold, تحويل بنكي)، وتنشئ طلب حقيقي في قاعدة البيانات.
- **صفحة "حسابي"** تعرض كل طلبات المستخدم وحالتها.
- **شات بوت ذكاء اصطناعي حقيقي** عبر Anthropic API (Claude)، عارف كل الخدمات والأسعار والمواعيد من قاعدة البيانات مباشرة، ويرد بنفس لغة العميل.
- تصميم مستقل (Dark navy + gold + rune-blue)، خط Spectral للعناوين وInter للنصوص، متجاوب بالكامل مع الموبايل.

## التشغيل محليًا

```bash
npm install
cp .env.example .env
# افتح .env وضيف مفتاح Anthropic API الحقيقي بتاعك في ANTHROPIC_API_KEY
# لو سبته فاضي، الموقع هيشتغل بالكامل ما عدا ردود الشات بوت الذكية (هيرجع رسالة توضح إن المفتاح غير مفعّل)
npm start
```

هيشتغل على `http://localhost:3000`.

**حساب تجريبي جاهز:** `demo@wingservices.gg` / `demo1234`

## متغيرات البيئة (.env)

| المتغير | الوصف |
|---|---|
| `PORT` | البورت اللي هيشتغل عليه السيرفر (افتراضي 3000) |
| `JWT_SECRET` | مفتاح سري لتوقيع جلسات الدخول — غيّره لأي نص عشوائي طويل قبل النشر الفعلي |
| `ANTHROPIC_API_KEY` | مفتاح Anthropic API لتفعيل الشات بوت الذكي (احصل عليه من console.anthropic.com) |

## ملاحظات مهمة قبل الاستخدام الفعلي (Production)

1. **الدفع تجريبي حاليًا**: صفحة الدفع بتسجل الطلب في قاعدة البيانات لكن مافيش بوابة دفع فعلية متصلة (زي Stripe أو Coinbase Commerce). قبل الإطلاق الحقيقي لازم تربط بوابة دفع حقيقية بدل الـ `checkout` الحالي.
2. **قاعدة البيانات**: بتستخدم `node:sqlite` المدمجة في Node.js 22+ (ملف واحد `db/wingservices.db`). لحجم استخدام أكبر يُفضّل الانتقال لـ PostgreSQL.
3. **الشات بوت**: بيبعت آخر 12 رسالة من المحادثة + كل الكتالوج الحالي كـ system prompt لكل طلب، وده كافي لعدد استخدام متوسط. لو الترافيك كبر، فكر في تلخيص المحادثات الطويلة.
4. **الأمان**: غيّر `JWT_SECRET` في `.env`، فعّل HTTPS، وحط الموقع خلف reverse proxy (Nginx) قبل أي استخدام حقيقي.
5. المحتوى (الأسعار، المراجعات، الأرقام) كله بيانات تجريبية للعرض — غيّرها بمحتواك الحقيقي قبل النشر.
